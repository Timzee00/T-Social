# Implemented features and gaps

This matrix describes source in this repository, not claims made about unavailable ZIP files. Instagram's feature availability changes by country, account and release; this is a product roadmap, not a complete reverse-engineering claim.

| Surface       | Implemented here                                                                                                                     | Remaining work                                                                                                                                                |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accounts      | Google, Facebook, phone Verify and ChatGPT OIDC provider implementations; secure sessions; device revocation; explicit OAuth linking | Provider registration/live acceptance tests; passkeys/app MFA; safe recovery for lost phone/provider access; complete account deletion/export workflow        |
| Posts         | Photos, videos, 10-item carousels, captions, image description, location text, likes, comments, comment deletion, saves, links       | Collaborator invitations; mentions/tags and approvals; edit media/captions; reposts; collections; scheduled publishing                                        |
| Feeds         | Bounded chronological retrieval, Following and Reels filters, cursor API, permission filtering                                       | Learned recommendations, interest controls, scalable discovery/search, infinite-scroll UI                                                                     |
| Reels         | Video validation/conversion, playback and a Reels filter                                                                             | Dedicated swipe player, licensed music, Remix, templates, editing tools, captions/translations, Trial Reels, Friends activity/Blend                           |
| Stories       | 24-hour visibility, upload, viewer records, deletion, archive and Highlights                                                         | Video Stories, Close Friends, reactions/replies, stickers/polls, music, timed playback, Notes and Instants                                                    |
| Profiles      | Editing, avatar upload/fallback, approved private followers, block, pinned posts                                                     | Followers list/removal; restrict/mute; multi-account switching; verified identity tools                                                                       |
| DMs           | Direct text messages, polling, read state, sender unsend, follower permission                                                        | Group membership/requests; attachments; voice notes; typing/presence; calls; replies, edits, reactions, pins and scheduling; broadcast channels               |
| Safety        | Reports, admin review, bilateral block, media type validation, moderated-removal protection                                          | Automated abuse/content moderation; appeals; teen/parental controls; spam detection and operational response staff                                            |
| Recovery      | Post archive, Recently Deleted and 30-day restore                                                                                    | Robust full-account recovery/deletion and complete asynchronous data portability                                                                              |
| Creator tools | Actual post/like totals                                                                                                              | Reach/retention analytics, professional dashboards, payments, creator subscriptions, gifts/payouts, ads and business tools                                    |
| Map/live      | Location text on posts                                                                                                               | Opt-in location sharing/map permissions, geographic discovery; WebRTC/SFU live rooms and live recording                                                       |
| Operations    | SQL integrity/indexes, persistent rate limits, private storage, cleanup retry, release checks, Docker and CI                         | Error-monitoring provider; queue-backed media workers; CDN; distributed realtime/search; capacity/load, backup restore and deployed provider acceptance tests |

## Public reference points

Meta's [reposts, Map and Friends in Reels announcement](https://about.fb.com/news/2025/08/new-instagram-features-help-you-connect/) describes features absent from this release. OpenAI's [website sign-in guide](https://developers.openai.com/siwc/website) describes the provider flow implemented here; actual client approval is separate.

Implement the remaining features as complete vertical slices with ownership/privacy tests and user-facing failure states. Do not sell empty pages or database tables as finished features.
