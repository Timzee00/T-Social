# Feature matrix — October 2026

This describes the current source and tested workflows. It is not a claim of complete Instagram parity. Provider-dependent operations are distinguished from locally tested features.

| Requested surface                      | Current implementation                                                                                                                                                                                                              | Limits / remaining work                                                                                                                                                                                              |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| For You / Following                    | Permission-filtered feed, cursor pagination and Load more UI. For You ranks bounded pages using recency, follows, recent liked authors and author diversity.                                                                        | Transparent heuristic ranking; no trained recommendations, global search index or large-scale fanout.                                                                                                                |
| Posts / carousel / videos              | Up to 10 media items, actual carousel, normalized images and H.264/AAC videos, captions, alt text, text locations, archive, three profile pins and Recently Deleted.                                                                | No collaborator posts, caption editing, scheduled publishing, mentions or native video editor.                                                                                                                       |
| Reels / Friends                        | Reels filter, video playback and a mutual-followers Reels surface.                                                                                                                                                                  | No swipe player, Blend, Remix, licensed music, trials or trained discovery.                                                                                                                                          |
| Likes / comments / replies             | Likes, comments, replies, comment likes and authorized deletion. Restricted comments are hidden from other readers.                                                                                                                 | No threaded deep nesting UI or moderation appeals. Replies are labeled and use server-validated parent IDs.                                                                                                          |
| Saves / collections                    | Private collections, add from post menu, collection view/delete; unsaving removes collection membership.                                                                                                                            | Collections are private, bounded to 100 visible rows per view.                                                                                                                                                       |
| Reposts                                | Idempotent repost/remove, profile repost display, original-author privacy reapplied.                                                                                                                                                | No separate notification/fanout service for friend repost activity.                                                                                                                                                  |
| Hashtags / search                      | Unicode hashtag extraction during post creation, indexed exact hashtag lookup and search dialog. Username search remains available.                                                                                                 | No external search cluster, fuzzy full-text content search or trending index.                                                                                                                                        |
| Profiles / private / follows           | Profiles, editing, rounded-square avatars, private accounts, follow/unfollow and owner-managed requests.                                                                                                                            | No follower removal UI, account switching, passkeys or complete deletion/recovery workflow.                                                                                                                          |
| Block / restrict                       | Bilateral blocking plus restricted comment visibility, notification suppression and restricted DM sending.                                                                                                                          | Restrict does not reproduce every Instagram presence/read-status rule.                                                                                                                                               |
| Notifications                          | Follow/request/like/comment activity and read state.                                                                                                                                                                                | No push notification delivery, group push, repost/story/gift fanout or email delivery.                                                                                                                               |
| Stories                                | 24-hour image/video Stories, views, reactions and replies, deletion, owner archive and Highlights. Close Friends enforced across Stories, views and Highlights.                                                                     | No stickers, polls, licensed music, timer editor or native capture attestation. Existing media links expire within two minutes after revocation.                                                                     |
| Close Friends                          | Owner-managed list, story/note audience filtering and Instant eligibility.                                                                                                                                                          | No shared/public list; list management is limited to 200 displayed members.                                                                                                                                          |
| Notes                                  | 60-character notes, 24-hour expiry, mutual followers or Close Friends.                                                                                                                                                              | No music/status extensions.                                                                                                                                                                                          |
| Instants                               | Camera capture UI, explicit recipients, Close Friends/mutual eligibility, atomic one-time opening and 24-hour expiry.                                                                                                               | No screenshot prevention guarantee. Browser capture is not device-attested. A failed connection after opening can consume the opening.                                                                               |
| Map                                    | Opt-in post coordinates, rounding to roughly 1 km, removal, interactive coordinate plot and external OpenStreetMap link.                                                                                                            | A post map, not live friend tracking or a full map-tile product. No automatic location sharing.                                                                                                                      |
| Direct messaging                       | Direct text, follower/privacy controls, read status and sender unsend.                                                                                                                                                              | The legacy direct-message view remains basic. Rich messaging below is in Groups & channels; a two-person group can use it. No automatic migration of direct chats into groups.                                       |
| Groups / attachments / reply transport | Up to 50 members, explicit invitation acceptance, no pre-join history, validated image/video attachments, server-checked reply targets, member-only retrieval.                                                                      | History has Older, Newer and Latest controls, bounded to 50 messages per page. No end-to-end encryption or push delivery.                                                                                            |
| Edit / delete / reactions / pins       | Sender-only 15-minute edits, unsend and cleanup; six selectable reactions with per-reaction counts and removal, three pins under a thread lock, and a separate pinned-message view.                                                 | Pins reapply membership, join boundary, blocks and deletion rules. The visible pin count can be below the thread-wide three-pin limit when some messages are inaccessible.                                           |
| Scheduling / read state                | Messages can be scheduled 30 seconds–29 days ahead; hidden until delivery; cancellation by unsend. Explicit displayed-message receipts avoid false reads for old pins, paged history and out-of-order scheduled delivery.           | Delivery appears when a client polls. No scheduled push worker.                                                                                                                                                      |
| Translation                            | Authorized LibreTranslate-compatible server integration; button shown only when configured.                                                                                                                                         | Requires a real HTTPS service and live acceptance tests. Language availability depends on that service; UI currently requests English.                                                                               |
| Requests / invite codes                | Persistent request settings, group accept/decline, hashed rotating invite codes with seven-day expiry, capacity and blocked-owner checks.                                                                                           | No dedicated unknown-sender inbox for legacy direct messages; those permissions are enforced before sending.                                                                                                         |
| Group calls                            | Not implemented.                                                                                                                                                                                                                    | Requires an SFU/TURN service, device-permission UI, membership revocation and live multi-device tests. No fake call controls are shipped.                                                                            |
| Music tools                            | Not implemented.                                                                                                                                                                                                                    | Requires licensed catalog/provenance, rights controls and a tested mixing/editor pipeline. No unlicensed popular tracks are bundled.                                                                                 |
| Creator tools                          | Per-post likes/comments/saves/reposts, gift records, active supporter records, caption drafts, broadcast channels.                                                                                                                  | Recent bounded records, not unique reach/watch-time analytics. Supporter memberships are coin-based support records, without exclusive-content entitlement enforcement.                                              |
| Settings / security records            | Privacy, theme, navigation language (English/French/Yoruba), message controls, sessions, session-created/logout/revocation records and wallet security events.                                                                      | Other UI text remains English. Complete portability/deletion, age checks and incident-alert operations remain work.                                                                                                  |
| Trust & safety                         | Content reporting and admin review; moderator removal cannot be restored by the author.                                                                                                                                             | No automated moderation, appeal workflow or large-scale staffing/abuse operations.                                                                                                                                   |
| Virtual wallet                         | Separate T Coins and NGN earnings; balanced, append-only journal; integer amounts, unique request references, serialized balances and retention. Signup/profile/first-post coin tasks; post gifts and 30-day supporter memberships. | Coins have no cash value; no coin purchases, deposits, exchange, interest or cash conversion. Coins are not proof of human uniqueness.                                                                               |
| Funded cash                            | Operator-funded budgets, verified task claims, review-reference uniqueness, PIN/fresh-session checks, reserved payouts, Paystack verification, reconciliation and dispute pause.                                                    | Cash defaults OFF. Operator identity review is manual, not an integrated KYC provider. Test-mode balances are simulated. Provider liquidity, settlement, fees, compliance and live failure cases require validation. |

Before advertising or selling the application, also read [launch readiness](LAUNCH-READINESS.md), [wallet operations](WALLET-OPERATIONS.md) and [validation](VALIDATION.md).
